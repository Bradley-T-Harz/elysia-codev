# Contributing to Elysia Codev

Keep the extension thin. Elysia core owns coding authority, policy gates, approvals, audits, and operation results.

Before adding a risky feature, define the Elysia core contract first:

- config policy
- schema
- route/service
- approval behavior
- audit result
- UI truth
- focused tests

Do not implement patch application, shell execution, git mutation, package installation, or autonomous loops directly in the extension.
