# Changelog

## 0.1.0

- Official v1-finalization local Developer-profile add-on foundation.
- Adds Elysia Activity Bar container and Coding Room webview.
- Adds local Elysia coding bridge client for `/coding/status`, `/coding/session/start`, `/coding/chat`, and `/coding/repo/inspect-preview`.
- Adds private XDG API authentication, real workspace trust and exact repository approval/revocation, read-only Git/SCM truth, deliberate context receipts, local session/context persistence, and sanitized settings truth.
- Adds patch proposal with VS Code native diff review, exact-approved apply receipts, and a backend-owned bounded command catalog with one live read-only diff check.
- Adds checkpoint-only Developer Lab plan/approve/next/stop flow with step/time budgets and no autonomous execution.
- Adds local VSIX packaging and Elysia dry-run-first Developer-profile install/doctor compatibility contracts. Public Marketplace installation and publishing remain unavailable.
