# Codev publication boundary

Codev is an individually approved public Add-on. Its repository and
VSIX must contain only portable source, public documentation, synthetic test
fixtures, and privacy-safe Git history. It carries no user profile, local API
credential, approved-repository list, private path, Website implementation,
Artisan implementation, company record, or operator runtime state.

Website, Artisan, and company repositories remain private. They are not rewrite
or publication inputs for Codev, and their account/profile/role/production state
must not be copied into this repository.

For every publication, Codev's complete reachable history must pass the history
verifier, its pre-sanitization private bundle must restore exactly, and the VSIX
must pass archive-level hygiene. Git author credit may remain by name;
private email metadata must use the verified privacy-preserving public identity.

Privacy sanitation does not authorize deleting product capability. An
established Codev workflow that is incomplete or broken is a requirement to
repair, harden, and test it. Named removal requires explicit release-owner
approval.

This contract does not authorize publication, a GitHub push, a Marketplace
listing, or installation enablement. Those remain later release decisions.
